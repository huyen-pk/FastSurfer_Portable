This fork of [FastSurfer](https://github.com/Deep-MI/FastSurfer) aims to make the original project more portable, easier to install and also add a GUI.

The derivative work is integrated into [Open Healthcare](https://github.com/huyen-pk/Open-Healthcare-CPP) which englobes multiple modalities and processing pipelines.
